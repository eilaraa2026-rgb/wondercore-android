# ALICE.EXE Companion — Powered by Green Quill Studios Engine

This repository is the official Android foundation for the **ALICE.EXE Companion**.

## Branding hierarchy

### Primary public identity
- ALICE.EXE Enterprises
- ALICE.EXE Companion
- Purple, black, silver, and luminous digital styling
- Tagline: **Imagine. Create. Connect. Endure.**

### Secondary technology attribution
- Powered by Green Quill Studios Engine
- Green Quill remains the shared engineering and publishing foundation
- Green Quill attribution is intentionally small inside the ALICE.EXE edition

## Included editions

The engine can still build ALICE.EXE, My Fun With Doh, Young Sherlock, and The Dark Hours editions, but the default and flagship experience is ALICE.EXE.

## Cloud build

Open GitHub Actions and run:

**Build Green Quill Studios Engine**

The resulting artifact contains the ALICE.EXE APK and the additional franchise preview APKs.
